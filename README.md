# 考公选岗（kaogong-xuangang）

给备考公务员的考生用的选岗工具：上传**当年岗位表**和**往年进面分数线**，按个人条件筛出能报的岗位，再按历史分数线与竞争热度排序，给出「冲 / 稳 / 保」分档、可解释的匹配理由，以及需要人工核对的清单。

只在本机运行，不联网、不上传任何数据。

> 重要：本工具只做初筛。最终能否报考以招录机关解释和当年公告为准；分档与推荐指数是启发式参考，不是录取概率。

## 最简用法：双击 `start.cmd`

1. 双击项目根目录下的 **`start.cmd`**，浏览器会自动打开 `http://127.0.0.1:8765/`。
2. 在页面里 **① 上传岗位表**（可多选）。表头、列名、年份会自动识别，不用改表。
3. **② 上传往年分数线**（可选，可多份）。年份和分数制式会自动识别，识别错了就在文件旁边改。
4. **③ 填个人条件**（浏览器会记住；可以填意向工作地区、勾选优先户籍/生源所在地），点 **开始筛选**。
5. 看结果，下载 Excel 报告或打开网页版报告。

整个过程**不需要手写 `manifest.toml`，不需要编辑 `config/bob.toml`**。第一次用可以直接点右上角「先看示例数据」，不用准备任何文件。

关闭 `start.cmd` 的黑色窗口即停止服务；页面上的「数据检查」会列出识别过程和需要核对的地方。

## 环境（只有第一次需要）

需要 Python 3.11+，并安装：

```bat
pip install pandas openpyxl XlsxWriter
```

`start.cmd` / `run.cmd` 会自动寻找装了这些依赖的 Python（优先 DSH 自带运行时）。Windows 默认禁止运行 `.ps1`，所以入口都用 `.cmd`。

## 网页端能力

- **拖拽或点选**上传，可多文件；国考职位表按系统拆成多个文件也能一起传。支持 `.xlsx / .xlsm / .xls / .csv`，旧版 `.xls`（含政务网站导出的 HTML 伪 xls）也能直接读。
- 上传后立刻显示：识别到几个 sheet、表头在第几行、多少行数据、命中了哪些列。
- 自动识别岗位年份、分数线年份、满分（100/150/200/300）、分数类型；识别结果可手动覆盖。
- **没有分数线也能先筛岗位**，只是没有预测分和分档。
- 个人条件保存在本机浏览器（localStorage），下次打开自动恢复；也可以手动「保存条件」。
- 结果页支持按状态筛选、搜索、排序、点行看判定明细和近三年分数。
- **选岗偏好**：可以填意向工作地区、勾选优先户籍/生源所在地；结果页有「优势」标签和「只看意向地区」筛选。
- 报告一键下载：Excel（9 个 sheet）、网页版、文字摘要。
- 示例数据按钮：一键跑通内置的国考 / 广东省考仿真数据。

## 命令行用法（可选，适合批量或自动化）

```bat
run.cmd init                                  :: 生成 config/bob.toml、data/manifest.toml 等模板
run.cmd import --inspect <文件> --kind positions   :: 只读诊断列映射
run.cmd run --config config\bob.toml --positions data\incoming\positions --history data\incoming\history --out out\2027
run.cmd links --out out\2027 --limit 30       :: 看待人工核对的分数线匹配
run.cmd serve                                 :: 只启动网页（不自动开浏览器）
```

数据放 `data/incoming/`，在 `data/manifest.toml` 里登记年份/考试/分数制式（格式见 [数据契约](docs/data-contract.md)）。输出在 `out/<年份>/`：

| 文件 | 内容 |
|---|---|
| `report.xlsx` | 9 个工作表：推荐岗位、全部符合、存疑核对、不符合、岗位历史、匹配链路、未匹配分数线、数据质量、说明 |
| `report.html` | 自包含网页报告，双击打开即可 |
| `summary.txt` | 文字摘要 |
| `links.csv` / `links_review.csv` / `links_unmatched.csv` | 分数线与岗位的对应关系、待人工核对、未匹配 |
| `normalized/*.csv` | 标准化后的岗位与分数记录 |
| `issues.csv` | 数据质量问题与清洗动作 |

## 判定与排序怎么做的

- **三态结论**：满足所有硬条件 → `符合`；存在无法自动判定的条件（缺证据、表述含糊）→ `存疑`；明确违反硬条件 → `不符合`（列出失败维度）。
- **主观偏好也参与排序**：可以填「意向工作地区」（如 `广州,深圳`）或勾选「优先户籍/生源所在地」，命中会提高推荐指数；结果页有「只看意向地区」筛选和「优势」标签。
- **限制即优势**：限性别、限户籍、限民族、限基层项目、限证书等岗位，对符合条件的考生会形成竞争壁垒，报告里用「选岗优势」标出并加指数。比如「限男性」的岗位对男生是优势；对女生则直接判定不符合。
- **判定维度**：学历、学位、专业、政治面貌、民族、应届身份、基层工作经历、服务基层项目、执业资格、户籍/生源、性别、年龄、院校层次、特殊身份，以及从「备注」里抽取的附加条件。
- **分数线匹配**：优先职位代码，其次「部门 + 用人司局 + 职位名称」；代码跨年变化时用部门/职位名/代码前缀综合判断。**分数线只提取「岗位名称/代码 + 分数」**，不把往年的专业、学历、政治面貌当成你的条件——判定始终用今年的岗位表。置信度不足的记录不会计入历史分，而是在报告的「匹配链路」里标出，可用 `data/manual_links.csv` 人工指定。
- **多格式兼容**：一个分数线文件里可以有多年的 sheet、不同城市的 sheet、纯汇总 sheet；会按 sheet 标题/名称/年份列分别识别年份，跳过没有分数或没有岗位标识的 sheet。
- **混合分数制式**：国考里铁路公安、银保监等使用 100 分制合成成绩，和普通职位的 200 分制混在同一份表里；工具会按部门/单位分组自动推断，再统一折算后比较。
- **预测进面分**：近 3 年最低进面分按 `0.5 / 0.3 / 0.2` 加权，跨分数制式先折算；样本不足会在报告里标「置信度低」。
- **冲 / 稳 / 保**：`你的预估分 − 预测进面分` 的差值 ≥10 → 保，4~10 → 稳，0~4 → 冲，<0 → 风险。
- **推荐指数**：分数适配 45% + 竞争热度 20% + 招录容量 15% + 意向地区 10% + 竞争壁垒 10%，权重可在 `config/scoring.toml` 调整。

## 省考怎么用

网页端：考试类型选「省考」，填省份（如 `广东省`），上传省考职位表和分数线即可；广东 / 江苏 / 山东会自动套用对应列名预设。

命令行：

```bat
run.cmd run --config config\bob.toml ^
  --positions data\incoming\positions\2026广东省考职位表.xlsx ^
  --history data\incoming\history\2025广东省考进面分数.xlsx ^
  --preset guangdong --exam shengkao --province 广东省 --year 2026 ^
  --history-year 2025 --history-scale 300 --estimated-score 240 --score-scale 300
```

- 内置预设：`guokao`、`shengkao_generic`、`guangdong`、`jiangsu`、`shandong`。
- 省考专业目录差异大：可用 `--major-catalog 本省专业目录.xlsx` 导入（列名尽量接近「专业名称/专业代码/专业类/门类」）。

## 常见问题

- **表头识别不对**：用 `run.cmd import --inspect` 看每一列的匹配结果；网页端上传后也会显示命中了哪些列。
- **分数是区间、全角数字、`未公布`**：导入时自动清洗并记录到「数据质量」。
- **同一岗位多行（每人一行）**：自动聚合最低/最高分与进面人数。
- **分数线匹配错了**：编辑 `data/manual_links.csv` 手工指定，重跑后人工结果优先级最高。
- **分数线文件里有很多 sheet/年份**：会按每个 sheet 的标题、名称、年份列识别年份；说明、汇总、没有分数或没有岗位标识的 sheet 自动跳过。
- **同一职位代码重复**：按部门、单位、职位名区分；报告里会说明有多少条。
- **分数制式不确定**：网页上每个分数线文件旁可以手动选 100/150/200/300；留空则按部门/年份自动推断（同一场考试可能混用 100 和 200 分制）。
- **报告里 `—`**：没有历史分、无法预测或没有分档。
