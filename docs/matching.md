# 分数线与岗位的对应策略

核心难点：往年职位代码一年一变，民间分数线表又常常缺代码、缺用人司局、部门名写法不一。工具用「先精确、再归一、最后模糊」的分层策略，并且**低置信度的对应不会计入历史分**，而是列出来让你人工确认。

## 1. 归一键

对部门、用人司局、职位名称、职位属性做归一：

- 全角数字/字母转半角；统一括号；去空白与常见标点。
- 去掉「（参照公务员法管理）」「（参公）」「（本级）」等尾注。
- 职位名里的「（职位代码：…）」先抽走再比较。
- 省考里「雷州市」和「湛江市雷州市」这类包含关系也视为同部门候选。

归一后的实体键：`部门 | 用人司局 | 职位名称 | 职位属性`。

**分数线表只取「岗位名称/代码 + 分数」**。表里的专业、学历、政治面貌等列不会参与匹配，更不会用于判断 Bob 能不能报；这些条件始终来自今年的岗位表。

## 2. 匹配优先级

| 优先级 | 规则 | 置信度 | 是否计入历史分 |
|---|---|---|---|
| 1 | `data/manual_links.csv` 人工指定 / 忽略 | 1.0 | 是（action=link） |
| 2 | 职位代码相同（同考试、同省份） | 1.0 | 是 |
| 3 | 代码相同但源表里有多条：再按部门/名称/单位选出唯一 | 1.0 | 是 |
| 4 | 部门 + 用人司局 + 职位名称完全一致 | 0.95 | 是 |
| 5 | 部门相同 + 职位名称相似 ≥0.92，且与第二名有差距 | 0.92~1.0 | 是 |
| 6 | 部门是包含关系（雷州市 vs 湛江市雷州市）+ 名称相似 | 0.9 左右 | 是（仅唯一候选） |
| 7 | 相似度 0.78~0.92 或存在并列候选 | — | 否，进 `links_review.csv` |
| 8 | 分数线缺部门，仅按职位名唯一命中 | 0.8 | 否，进复核 |
| 9 | 部门对不上、名称相似度太低 | — | 否，进 `links_unmatched.csv` |

模糊打分（有职位代码时）：

```
0.40 × 职位名相似度 + 0.25 × 用人司局相似度
+ 0.10 × 职位属性 + 0.25 × 职位代码相似度（公共前缀/整体相似）
```

代码跨年变化时，公共前缀往往能区分同部门下的不同岗位；部门用倒排索引分组，只在同部门（含包含关系）内比较。

## 3. 人工修正

看 `out/<年份>/links_review.csv` 和 `links_unmatched.csv`，在 `data/manual_links.csv` 追加：

```csv
history_source,history_year,dept,post_name,position_id,action,note
2026国考进面分数线.xlsx,2026,国家税务总局广东省税务局,一级行政执法员（一）,2027-guokao-全国-100110001001,link,人工核对
```

- `history_source`：分数线文件名（含 `.xlsx` 也行，会取文件名主干）。
- `dept` / `post_name` 留空表示通配（按职位名 + 年份匹配）。
- `action=ignore`：这条分数线不参与任何岗位。
- `history_key` 在 `links.csv` 里格式为 `年份|文件名|sheet|行号`，用它可以定位到原始行。
- 人工结果优先级最高，重跑不会覆盖。

## 4. 未匹配的分数线怎么用

- 只做统计展示（「未匹配分数线」页），不会硬塞给某个岗位。
- 如果某岗位当年被拆分/合并，建议人工指定到最接近的新岗位，并在 note 里写清依据。

## 5. 置信度与预测

- 有 3 个及以上年份 → 置信度高；2 年 → 中；1 年 → 低；没有 → 无。
- 存在待人工核对的链路时，报告会在该岗位下注明「有 N 条匹配存疑，未计入历史分」。
- 不同分数制式（100/150/200/300）先折算到 200 分制再加权，最终按最近一年的制式展示。
