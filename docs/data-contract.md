# 数据契约与容错

本文说明工具怎么读文件、哪些列是必需的、脏数据怎么处理。

**用网页端时不需要看 manifest**：上传后会自动识别表头、列名、年份、分数制式，识别结果显示在文件下方，错了可以直接改。下面的声明方式只用于命令行批量运行。

真实文件对不上时，先用：

```bat
run.cmd import --inspect <文件或目录> --kind positions
run.cmd import --inspect <文件或目录> --kind history
```

`--inspect` 只读，不写任何文件，会打印表头所在行、每个标准字段命中的列、置信度和可复制到预设里的 TOML 片段。

## 1. 岗位表

### 1.1 必需列

| 标准字段 | 常见列名 | 说明 |
|---|---|---|
| 部门名称 | 部门名称、招录机关、招录单位、主管部门 | 与分数线对应时最关键 |
| 职位名称 | 招考职位、职位名称、岗位名称、招录职位 | 可含 `（职位代码：…）`，会自动抽取 |
| 招考人数 | 招考人数、招聘人数、招录人数、计划招录人数 | 无法解析时记 0 并写数据质量 |
| 专业 | 专业、专业要求、专业名称及代码、研究生/本科/大专专业名称及代码 | 多列会按学历层级分组 |
| 学历 | 学历、学历要求、最低学历 | 支持「本科及以上」「仅限本科」等写法 |

缺关键列不会直接崩溃，但会在报告里给出 warning；缺职位名称的行会被跳过。

### 1.2 可选列

部门代码、用人司局/单位、机构性质、职位代码、职位属性、职位分布、职位简介、学位、政治面貌、基层工作最低年限、服务基层项目工作经历、是否要求应届、资格证书、户籍要求、民族要求、性别要求、最低服务年限、考试类别、面试人员比例、工作地点、落户地点、备注/其他条件。

### 1.3 读取规则

- Excel：`.xlsx` / `.xlsm` 用 openpyxl 读取；`.xls` 用内置解析器读取（见下），多 sheet 逐个读取并合并。
- 旧版 `.xls`：支持 Excel 97-2003（BIFF8）、Excel 5.0/95（BIFF5），以及常见的「伪 xls」——HTML 表格、Excel 2003 XML、制表符/逗号分隔文本。加密的 .xls 会提示先取消密码；Excel 4.0 及更早格式请先用 Excel 另存为 .xlsx。
- 旧版 `.xls` 的日期单元格会按 Excel 序列号显示（岗位表里很少出现），公式取缓存值。
- CSV：自动尝试 UTF-8 / GB18030 / GBK 编码，自动识别逗号、制表符、分号。
- 表头识别：在前 10 行里选「命中已知列名最多」的一行；表头上方的标题行会被跳过。
- 合并单元格：表头区域的值会填满整个合并区域（例如两行表头）。
- 所有单元格按文本读取，避免 12 位职位代码被 Excel 当成数字后丢位。
- 空行、重复表头、完全重复的岗位会被跳过，并记录在「数据质量」页。
- 职位代码缺失时，用「年份-考试-省份-部门-职位-来源行」生成稳定 id。

## 2. 分数线表（民间整理）

### 2.1 manifest 声明

`data/manifest.toml`：

```toml
[[history]]
file = "data/incoming/history/2026国考进面分数线.xlsx"
exam = "guokao"          # guokao | shengkao
province = "全国"         # 省考填 "广东省"
year = 2026
kind = "笔试最低进面分"    # 笔试最低进面分 | 综合成绩 | 面试成绩
scale = 200              # 100 | 150 | 200 | 300
```

- `year` 也可以交给文件里的年份列或文件标题/文件名识别；都识别不到时会在数据质量里报 warning，记录不参与统计。
- 一个工作簿里可以有多个年份、多个城市的 sheet：会优先用每个 sheet 的标题/名称/年份列识别年份，`manifest` 里的 `year` 只是兜底。
- 一个文件里混了多年份：按年份列拆分，分别处理。
- `kind = 综合成绩 / 面试成绩` 的记录只存档，不参与「预测进面分」；如果一张 sheet 只有面试/综合成绩，会跳过并提示。
- `scale` 不写时按「部门/单位」分组推断（国考同一张表可能混用 200 分制和 100 分制合成成绩），推断结果会写入数据质量页；**建议留空让工具自动判断**，或在明确知道制式时写死。

### 2.2 常见列与容错

| 标准字段 | 常见列名 |
|---|---|
| 职位名称 | 职位名称、岗位名称、招考职位、岗位 |
| 部门名称 | 部门名称、招录机关、招考单位、招录单位、单位名称 |
| 职位代码 | 职位代码、岗位代码、职位编码 |
| 最低进面分 | 最低进面分、进面最低分、最低面试分数、进面分数线、最低分、入面分数线、笔试成绩、笔试分数、进面分 |
| 最高进面分 | 最高进面分、最高分、最高笔试成绩 |
| 招考人数 | 招考人数、招聘人数、招录人数、录用人数 |
| 进面人数 | 进面人数、面试人数（单独记录，不会当成招考人数） |
| 报名人数 / 竞争比 | 对应列名 |

**分数线表只使用「岗位名称/代码 + 分数」**。表里如果同时有专业、学历、政治面貌等列，会被忽略；这些条件一律以今年的岗位表为准。

自动处理：

| 现象 | 处理 |
|---|---|
| 全角数字、`分`、`约`、千分位 | 归一后转数值 |
| `132.5-140.2`、`132.5~140.2` | 拆成最低/最高分 |
| `未公布`、`—`、空 | 记为缺失，不参与统计 |
| 岗位名里带 `（职位代码：100110001001）` | 抽出职位代码 |
| 完全重复的行 | 去重并计数 |
| 同一岗位每人一行 | 聚合：最低=各最低分的最小值，最高=各最高分的最大值，进面人数=行数 |
| 同一年同一岗位多个来源文件 | 正常合并；相同记录去重 |

## 3. 列名别名与预设

- 内置预设：`xuangang/resources/presets/`（guokao、shengkao_generic、guangdong、jiangsu、shandong）。
- 你的覆盖：`config/presets/<同名>.toml`，按字段覆盖，支持 `[meta] extends = "父预设"`。
- 字段名参考：`xuangang/ingest/columns.py` 里的 `FIELD_DISPLAY`。
- 列名匹配顺序：精确归一 > 表头包含别名（长度差 ≤4）> 别名包含表头。这样「专业」不会误命中「是否在面试阶段组织专业能力测试」。

## 4. 数据质量记录

每条问题都包含：级别（info/warn/error）、文件、sheet、行号、说明、采取动作、字段。`error` 级问题（如整张分数线表找不到分数列）会跳过该 sheet，并在终端提示。

## 5. 专业目录

- 内置国考常用本科/研究生目录子集（门类 → 专业类 → 专业）。
- 无法判定的专业会标「存疑」，不会强行判不符合。
- 省考可用 `--major-catalog 本省专业目录.xlsx` 覆盖；表头尽量包含「专业名称 / 专业代码 / 专业类 / 门类」之一。
